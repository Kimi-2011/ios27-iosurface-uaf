## 二、关键事实（已证实）

1. **iOS 27.0.1 没有任何公开 CVE**；其 kernelcache 与 27.0 **完全一致**（301 kext 零改动）
   → 27.0.1 是纯用户态更新
2. **Calif 团队在 iOS 27 安全说明中署名 4 条 CVE**：
   - `CVE-2026-28968` Kernel，**越界写 → 内核内存破坏**（genter0/Svetoslav Stolarov/Josh Maine）
   - `CVE-2026-65410` **AVEVideoEncoder**，"改进检查"（Calif.io + Claude/Anthropic）
   - `CVE-2026-65409` Foundation，类型混淆（Bruce Dang）
   - `CVE-2026-86886` TCC，路径穿越
3. 普通第三方 app 可触达：**290 个 Mach 服务**（其中 59 个回应消息）、5 个 IOKit 服务
4. ANE 内核驱动对普通 app 不可达（0 实例 + 需私有授权）；CoreML 走用户态路径

## 三、已被证伪的方向（避免重复投入）

| 方向 | 证伪依据 |
|---|---|
| sandbox 27.2 改动 | 是字段 getter 与 7 比较，功能分流 |
| AppleSEPKeyStore 27.2 改动 | 新增密钥类型 2 的支持，功能 |
| IOSurface 27.2 UAF 加固 | 内核 user client 方法对 app 全 NotPrivileged |
| AVE2 "7 项新边界" | 那些字段在 27.0.1 结构体里不存在（布局变化） |
| AVE2 `0x3f/0x40` 边界 | 27.0.1 已存在同样检查（11 处） |
| XPC 盲 fuzz 致守护进程崩溃 | 时间巧合，无法复现（3 种方式验证） |
| 跨版本按结构体偏移比对 | 布局在版本间变化，前提不成立 |

## 四、方法学排名（按投入产出）

1. **字符串集合差分** —— 10 秒定位子系统，最有效
2. **Mach 服务枚举** —— 2 秒得到 290/59，攻击面地图
3. 形状哈希差分 —— 快，但需配合人工判读
4. 逐函数反编译 —— 昂贵，产出多为"功能变更"
5. 常量集合差分 —— **不可用**（被日志行号污染）
6. 盲 fuzz —— 无产出（缺协议 schema 与覆盖率）

## 五、现实结论

- 27.0.1 上可触及的内核攻击面（IOKit）基本关闭；ANE/AGX/PPM/Pearl 全需私有授权
- 用户态攻击面很大（290 服务），但**代码在加密系统卷，无法差分**
- 我们唯一能观察"未修补窗口"的是 **27.0.1 → 27.2**，而 27.2 的安全说明尚未发布
- **结论：等 27.2 正式版安全说明，是当前性价比最高的动作**
